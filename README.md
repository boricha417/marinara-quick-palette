# 퀵 팔레트 1.3.10 (Marinara Engine 확장)

Marinara Engine 개인 확장입니다. (2.4.x ~ 2.5.1까지 호환 확인) 채팅 입력창의 **파일 첨부 버튼 자리에 `+` 메뉴**를 두고, 자주 쓰는 동작을 한곳에 모읍니다. 대사 따옴표와 나레이션 기호 빠른 입력, 이미지 첨부, 자주 쓰는 문구 메모 보관함, 턴 북마크 열기를 한 메뉴에서 꺼냅니다. 각 항목은 체크해 두면 입력창 위에 **미니 탭**으로 늘 보이게 할 수 있습니다.

## 들어가는 자리

- 채팅 입력창 왼쪽의 **첨부(클립) 버튼이 `+` 버튼으로 바뀝니다.** 순정 파일 입력은 그대로 두고 메뉴의 "이미지 추가"가 그것을 대신 눌러 주므로, 첨부 기능은 잃지 않습니다.
- 채팅방을 열지 않은 상태(홈, 캐릭터 목록 등)에서는 메뉴 항목을 눌러도 "채팅방을 먼저 열어주세요"만 뜹니다.

## 메뉴 항목

| 항목 | 동작 |
| --- | --- |
| 대사 따옴표 | 커서 자리에 `""`를 넣고 가운데에 커서를 둡니다. 글을 선택한 상태면 선택 부분을 따옴표로 감쌉니다. 지금 문단에 따옴표가 홀수 개면 닫는 것 하나만 넣습니다. |
| 나레이션 | 같은 방식으로 `*`를 넣거나 감쌉니다. 메뉴의 `*` 아이콘은 폰트에 따라 위치가 흔들리지 않도록 그림으로 그렸습니다. |
| 이미지 추가 | 마리나라 순정 파일 선택 창을 엽니다. |
| 메모 | 자주 쓰는 문구 보관함을 엽니다(아래 참고). |
| 북마크 | **턴 북마크** 확장의 런처를 대신 눌러 줍니다. 턴 북마크가 설치·활성화되어 있지 않으면 이 항목은 메뉴와 탭에서 아예 보이지 않습니다. |

각 항목 옆 **체크박스**를 켜면 그 항목이 입력창 위에 미니 탭으로 붙습니다. 탭은 체크한 순서대로 늘어서고, 색은 입력창 외곽선 색을 따라가며, 아이콘 색은 배경 밝기를 재서 자동으로 고릅니다. 탭은 입력창이 실제로 보일 때만 나타나고, 채팅방 목록이 채팅 화면을 덮고 있을 때는 숨깁니다.

## 메모 보관함

| 기능 | 설명 |
| --- | --- |
| 새 메모 추가 | 제목과 내용. 제목 칸은 모바일 키보드의 자동완성 바를 피하려고 한 줄짜리 textarea입니다. |
| 입력창 / 복사 | 메모 내용을 커서 자리에 넣거나 클립보드로 복사합니다. |
| 위에 고정 | 고정한 메모는 목록 맨 위 묶음에 모입니다. |
| 위로 / 아래로 | 표시 순서를 직접 바꿉니다. 순서는 저장됩니다. |
| 수정 / 삭제 | 삭제는 두 번 눌러야 지워집니다("한 번 더 누르면 삭제됩니다"). |
| 검색 | 제목이나 내용으로 찾습니다. |

메모는 **확장 전용 서버 저장소**(`marinara.storage`)에 저장되어 어느 기기에서 열어도 같고, 브라우저에도 사본을 두어 서버 응답 전에도 바로 보입니다. 저장소 한도는 확장당 1MB입니다.

## 알아둘 점

- **모바일**에서 `+`·탭·메뉴를 눌러도 입력창 포커스와 키보드가 유지됩니다.
- 글자 삽입은 입력창의 값을 직접 바꾼 뒤 입력 이벤트를 보내는 방식이라 마리나라의 자동 저장·초안 기능과 같이 동작합니다.
- **확장 서랍**과 같이 써도 미니 탭이 서랍에 수집되지 않도록 만들었습니다. 탭은 화면 폭 전체를 차지하는 투명한 받침 안에 있어 서랍의 자동 수집 기준(작은 고정 요소)에 걸리지 않습니다.
- 메뉴와 메모 창은 글로벌 노트와 같은 저널풍 디자인(종이·잉크·초록 포인트)입니다.
- 엔진이 입력창 구조를 바꾸면 `+` 버튼이 안 생길 수 있으니 아래 표식을 확인하세요.

## 확장이 기대는 화면 표식

- 입력창 껍데기: `.marinara-chat-input-shell`
- 입력 칸: `textarea[data-chat-composer="true"]` 또는 `textarea.mari-chat-input-textarea`
- 순정 파일 입력: 껍데기 안의 `input[type="file"]`. 원래 첨부 버튼은 그 바로 뒤의 `button`으로 보고 CSS로 숨깁니다.
- 대화 영역(탭 표시 조건): `[data-chat-scroll]` 또는 `.mari-messages-scroll`
- 턴 북마크 런처: `.tb-floating-launcher`, `.tb-topbar-launcher`
- 탭 색 토큰: `--marinara-chat-chrome-input-border`

엔진이 이 구조를 바꾸면 해당 자리만 손보면 됩니다.

## 설치

1. **설정 → 고급 → 위험 구역**에서 "외부 확장 가져오기 허용"을 켭니다.
2. **설정 → 애드온 → 외부 확장**에서 이 저장소의 zip 또는 폴더(`manifest.json`, `extension.js`, `extension.css`)를 가져옵니다. GitHub 확장 관리자 확장을 쓰면 저장소 주소를 등록해 업데이트도 받을 수 있습니다.
   설치용 zip은 저장소에 올려 둔 `퀵 팔레트_v1.3.10.zip`입니다(파일을 열고 **Download** 버튼). 저장소 전체를 "Download ZIP"으로 받으면 폴더가 한 겹 더 있어 바로 설치되지 않습니다.
3. 가져온 확장은 꺼진 상태로 들어옵니다. 코드 해시를 확인하고 **승인 → 활성화**합니다. 코드가 바뀔 때마다 다시 승인해야 합니다.

이 확장은 `marinara.extension` 종류로, 마리나라 페이지 안에서 그대로 실행됩니다(full page access). 페이지에 보이는 것을 읽고 바꿀 수 있는 권한이므로 코드를 확인한 뒤 승인하세요.
